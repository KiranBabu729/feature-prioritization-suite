# Prioritization Studio

Two parts, run together:

- [`server/`](./server) — Express API that calls Claude to score feedback against PDL-defined factors. See its README for OAuth setup — this is the part that needs authentication.
- [`client/`](./client) — React UI for designing a prioritization matrix and testing it. See its README for usage.

See the [top-level README](../README.md) for the full end-to-end workflow across this app and the Roadmap App.
